# Bomberman - Projet Pygame

Implémentation du jeu **Bomberman** en Python avec **Pygame**, proposant un mode 1v1 local ainsi que des modes contre l'Intelligence Artificielle (waves et Boss).

## Plateformes supportées et prérequis
* **Systèmes d'exploitation** : Windows, macOS, Linux.
* **Python** : Version 3.10 ou supérieure.
* **Dépendances** : `pygame` (géré via `Pipenv` grâce aux fichiers `Pipfile` et `Pipfile.lock`).

## Installation et exécution

1. **Cloner le dépôt** :
   ```bash
   git clone https://github.com/Simon-1501/Projet_Info_Majeure.git
   cd Projet_Info_Majeure
   ```

2. **Installer Pipenv et les dépendances du projet** :
   ```bash
   pip install pipenv
   pipenv install
   ```

3. **Lancer le jeu** :
   ```bash
   pipenv run python main.py
   ```
